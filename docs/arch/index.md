# 신경망 구조

이 섹션은 데이터의 종류와 목적에 맞춰 발전해 온 신경망 구조를 다룹니다. 이미지를 위한 CNN, 순서를 위한 RNN, 그리고 둘을 대체하며 거의 모든 분야의 표준이 된 어텐션과 트랜스포머, 마지막으로 새로운 데이터를 만들어 내는 생성 모델(VAE, GAN, 확산 모델)까지 이어집니다.

| 페이지 | 핵심 질문 |
|---|---|
| [CNN](cnn.md) | 이미지에는 왜 합성곱이 맞고, ResNet은 무엇을 바꿨나? |
| [RNN과 LSTM](rnn.md) | 순서가 있는 데이터를 기억하며 처리하는 법과 그 한계는? |
| [어텐션](attention.md) | Query·Key·Value는 어디서 왔고, 셀프 어텐션은 무엇을 계산하나? |
| [트랜스포머](transformer.md) | 어텐션만으로 만든 구조는 어떻게 생겼고, 왜 LLM의 기반이 됐나? |
| [임베딩과 표현 학습](embeddings.md) | 단어·문장·이미지를 벡터로 바꾸면 무엇을 할 수 있나? |
| [오토인코더와 VAE](vae.md) | 데이터를 압축했다 복원하며 배우는 잠재 공간이란? |
| [GAN](gan.md) | 위조범과 감별사의 경쟁으로 진짜 같은 이미지를 만드는 법은? |
| [확산 모델](diffusion.md) | 잡음을 조금씩 걷어 내며 그림을 그리는 모델은 어떻게 학습하나? |

!!! basic "구조마다 품고 있는 가정"
    신경망 구조는 데이터에 대한 **가정(귀납 편향)**을 담고 있습니다.

    | 구조 | 가정 | 잘 맞는 데이터 |
    |---|---|---|
    | MLP | 없음 (모든 입력이 모든 출력과 연결) | 작은 표 데이터 |
    | CNN | 가까운 것끼리 관련 있고, 위치가 바뀌어도 같은 패턴 | 이미지, 음성 스펙트로그램 |
    | RNN | 순서대로 처리, 과거를 요약해 기억 | 짧은 시계열, 음성 |
    | 트랜스포머 | 무엇이 무엇과 관련 있는지도 데이터로 배움 | 텍스트, 그리고 데이터가 충분하면 거의 모든 것 |

    가정이 강할수록 적은 데이터로 배우지만, 데이터가 많아지면 가정이 약한 트랜스포머가 따라잡고 앞지릅니다.
