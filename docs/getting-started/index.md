# 시작하기

이 섹션은 본격적인 공부에 앞서 지도를 펼쳐 보는 곳입니다. AI가 어떤 길을 걸어 지금의 LLM에 이르렀는지, "AI·머신러닝·딥러닝·생성형 AI"가 서로 어떤 관계인지, 이 분야의 1차 자료인 논문과 모델 카드를 어떻게 읽는지, 그리고 내 목적에 맞는 읽기 순서는 무엇인지 정리합니다.

| 페이지 | 핵심 질문 |
|---|---|
| [AI의 역사와 세 번의 봄](history.md) | 1956년 다트머스 회의부터 ChatGPT까지, AI는 왜 두 번 겨울을 맞고 세 번째 봄을 맞았나? |
| [AI·머신러닝·딥러닝·생성형 AI](landscape.md) | 이 용어들은 서로 어떻게 포함되고, 무엇이 다른가? |

| [학습 로드맵](roadmap.md) | 비전공자, 개발자, 시스템·반도체 엔지니어는 각각 어떤 순서로 읽으면 좋을까? |

!!! basic "이 핸드북이 다른 입문서와 다른 점"
    1. **한 페이지 세 단계** — 같은 주제를 비유(기초) → 수식·코드(중급) → 논문 디테일(전문가) 순서로 깊게 내려갑니다. 처음에는 기초 상자만 읽고 넘어가도 됩니다.
    2. **짧은 코드** — 개념 페이지마다 PyTorch나 NumPy로 10–30줄 정도의 코드를 넣었습니다. 모두 실행해 보고 넣은 코드입니다.
    3. **시스템과 하드웨어** — 모델이 실제로 GPU·NPU·메모리 위에서 어떻게 돌아가는지, KV 캐시와 양자화가 왜 중요한지를 다른 입문서보다 깊게 다룹니다.
    4. **기준 시점 표기** — 모델 이름과 성능처럼 빨리 바뀌는 내용에는 "2026년 11월 기준"처럼 시점을 적었습니다.
