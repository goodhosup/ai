# LLM

이 섹션은 대규모 언어 모델이 만들어지는 과정을 처음부터 끝까지 따라갑니다. 글자를 토큰으로 자르고, 수조 개 토큰으로 다음 토큰 예측을 학습하고(사전 학습), 대화형 어시스턴트로 다듬고(미세 조정·선호 학습), 사용자가 프롬프트로 다루고, 답하기 전에 생각하게 만들고(추론 모델), 더 크고 긴 문맥을 다루기 위한 구조(MoE, 긴 문맥)까지 다룹니다.

| 페이지 | 핵심 질문 |
|---|---|
| [토큰화](tokenization.md) | LLM은 글자를 어떤 단위로 보고, 한국어는 왜 토큰이 더 많이 드나? |
| [사전 학습과 스케일링 법칙](pretraining.md) | 모델·데이터·계산을 얼마나 키우면 얼마나 좋아지나? |
| [미세 조정 (SFT·LoRA)](finetuning.md) | 사전 학습 모델을 내 목적에 맞게 적은 비용으로 고치는 법은? |
| [선호 학습 (RLHF·DPO)](alignment-training.md) | "좋은 답"을 사람의 선호로 가르치는 법은? |
| [프롬프트 설계](prompting.md) | 같은 모델에서 더 좋은 답을 끌어내는 입력은 어떻게 쓰나? |
| [추론 모델과 사고 사슬](reasoning.md) | 답하기 전에 길게 생각하는 모델은 어떻게 학습되고, 왜 수학·코딩을 잘하나? |
| [MoE (전문가 혼합)](moe.md) | 파라미터는 크게, 계산은 적게 하는 구조는 어떻게 동작하나? |
| [긴 문맥과 메모리](long-context.md) | 책 한 권을 한 번에 읽는 모델은 무엇이 어렵고 어떻게 해결하나? |

!!! basic "LLM이 만들어지는 세 단계"
    ```mermaid
    flowchart LR
        A["① 사전 학습<br/>인터넷·책·코드 수조 토큰<br/>다음 토큰 예측<br/>(수개월, 수천 GPU)"] --> B["② 지도 미세 조정<br/>질문-모범 답변<br/>수만–수백만 쌍"]
        B --> C["③ 선호·강화 학습<br/>사람 선호, 정답 검증<br/>RLHF·DPO·RLVR"]
        C --> D["어시스턴트 모델"]
    ```

    ①에서 지식과 언어 능력이, ②에서 지시를 따르는 대화 형식이, ③에서 도움이 되고 안전하며 깊이 생각하는 태도가 만들어집니다.
