# 미분과 경사하강법

!!! spec "핵심 논문 · 연도"
    Cauchy, 경사하강법 (1847) · Robbins·Monro, "A Stochastic Approximation Method" (1951, SGD의 기원) · Linnainmaa (1970, 역방향 자동 미분) · Rumelhart·Hinton·Williams (1986, 역전파) · Baydin 외, "Automatic Differentiation in Machine Learning: a Survey" (2018)

!!! basic "한눈에 보기"
    안개 낀 산에서 가장 낮은 골짜기로 내려가야 한다고 해 봅시다. 멀리는 안 보이지만 **발밑의 기울기**는 느낄 수 있습니다. 가장 가파르게 내려가는 방향으로 한 걸음, 다시 기울기를 느끼고 한 걸음… 이것이 **경사하강법**입니다.

    - 산의 높이 = **손실**(모델이 얼마나 틀렸나)
    - 내 위치 = **파라미터** 값들
    - 발밑의 기울기 = **그래디언트**(미분)
    - 한 걸음의 크기 = **학습률**

    딥러닝 모델은 파라미터가 수십억 개인 "수십억 차원의 산"을 이렇게 내려갑니다. 미분은 "이 파라미터를 조금 바꾸면 손실이 얼마나 바뀌나"를 알려 주는 도구입니다.

## 미분과 그래디언트 { .l2 }

함수 \(f(x)\)의 미분 \(f'(x)\)는 x를 아주 조금 바꿨을 때 f가 바뀌는 비율입니다.

\[
f'(x) = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
\]

변수가 여럿이면 각 변수에 대한 편미분을 모은 벡터가 **그래디언트**입니다.

\[
\nabla_\theta \mathcal{L} = \left(\frac{\partial \mathcal{L}}{\partial \theta_1}, \dots, \frac{\partial \mathcal{L}}{\partial \theta_n}\right)
\]

그래디언트는 손실이 **가장 빨리 커지는 방향**을 가리킵니다. 그래서 반대 방향으로 갑니다.

\[
\theta \leftarrow \theta - \eta\,\nabla_\theta \mathcal{L}
\]

| 자주 쓰는 미분 | 결과 |
|---|---|
| \(x^n\) | \(n x^{n-1}\) |
| \(e^x\) | \(e^x\) |
| \(\ln x\) | \(1/x\) |
| 시그모이드 \(\sigma(x)\) | \(\sigma(x)(1-\sigma(x))\) |
| ReLU \(\max(0, x)\) | x > 0이면 1, 아니면 0 |

## 연쇄 법칙: 역전파의 핵심 { .l2 }

함수가 겹쳐 있으면 미분은 **곱으로 이어집니다**.

\[
y = f(g(x)) \;\Rightarrow\; \frac{dy}{dx} = \frac{dy}{dg}\cdot\frac{dg}{dx}
\]

신경망은 층이 수십 개 겹친 함수이므로, 출력 쪽에서부터 연쇄 법칙으로 기울기를 곱해 가며 입력 쪽으로 전달하면 모든 파라미터의 그래디언트를 한 번에 구할 수 있습니다. 이것이 [역전파](../dl/backprop.md)입니다.

## 학습률의 영향 { .l2 }

| 학습률 | 증상 |
|---|---|
| 너무 작음 | 손실이 아주 천천히 줄어듦. 학습 시간 낭비 |
| 적당함 | 손실이 빠르게 줄고 안정적으로 수렴 |
| 너무 큼 | 골짜기를 넘어 반대편으로 튐. 손실이 출렁이거나 발산(NaN) |

실제로는 처음에 작게 시작해 키우고(워밍업), 학습이 진행되면 줄이는 **스케줄**을 씁니다 → [옵티마이저](../dl/optimizers.md).

## 확률적 경사하강법 (SGD) { .l2 }

손실은 원래 전체 데이터의 평균이지만, 데이터가 수조 토큰이면 한 걸음마다 전부 계산할 수 없습니다. 그래서 무작위로 고른 **미니배치**(예: 수백 개 샘플)의 그래디언트로 전체를 근사합니다. 그래디언트에 잡음이 섞이지만, 오히려 날카로운 골짜기에 빠지지 않게 돕는다는 해석도 있습니다.

## 코드로 보기 { .l2 }

\(f(w) = (w-3)^2\)의 최솟값(w = 3)을 경사하강법으로 찾고, PyTorch 자동 미분과 손 계산을 비교합니다.

```python
import torch

w = torch.tensor(0.0, requires_grad=True)
lr = 0.1
for step in range(50):
    loss = (w - 3) ** 2
    loss.backward()                 # dL/dw = 2(w-3) 자동 계산
    with torch.no_grad():
        w -= lr * w.grad
    w.grad.zero_()
print(round(w.item(), 4))           # 3.0 근처

# 수치 미분으로 자동 미분 확인 (x=1.5에서 sin(x)·x²)
x = torch.tensor(1.5, dtype=torch.float64, requires_grad=True)
y = torch.sin(x) * x ** 2
y.backward()
h = 1e-4
f = lambda v: torch.sin(torch.tensor(v, dtype=torch.float64)) * v ** 2
numeric = (f(1.5 + h) - f(1.5 - h)) / (2 * h)
print(round(x.grad.item(), 6), round(numeric.item(), 6))
```

첫 줄은 `3.0`입니다(50걸음 뒤 실제 값은 \(3(1-0.8^{50}) \approx 2.99996\)). 둘째 줄의 두 값은 소수 여섯째 자리까지 같습니다. 학습률을 1.1로 바꾸면 w가 발산하는 것을 직접 볼 수 있습니다.

??? expert "전문가 노트 — 자동 미분의 두 방식, 야코비안, 2차 정보"
    **전방 모드와 역방향 모드.** 자동 미분은 계산 그래프를 따라 연쇄 법칙을 기계적으로 적용합니다. 입력 n개, 출력 m개인 함수에서 전방 모드는 입력 하나당 한 번(비용 ∝ n), 역방향 모드는 출력 하나당 한 번(비용 ∝ m) 그래프를 지나갑니다. 신경망 학습은 "파라미터 수십억 개 → 손실 1개"이므로 역방향 모드(역전파)가 압도적으로 유리합니다. 대신 순전파의 중간값(활성값)을 저장해야 해서 메모리를 많이 씁니다 → [초기화와 학습 안정성](../dl/training-stability.md)의 활성값 체크포인팅.

    **야코비안과 벡터-야코비안 곱.** 벡터 함수의 미분은 행렬(야코비안)입니다. 역전파는 야코비안을 실제로 만들지 않고 "위에서 내려온 그래디언트 벡터 × 야코비안"(VJP)만 계산합니다. 예를 들어 (d × d) 행렬 곱 층의 VJP는 또 하나의 행렬 곱이라, 역전파 계산량은 순전파의 약 2배가 됩니다(입력 기울기 + 가중치 기울기). 학습이 순전파의 약 3배, 즉 6N FLOPs/토큰인 이유입니다.

    **2차 정보.** 헤시안(2차 미분 행렬)은 곡률을 알려 줍니다. 곡률이 크면 작은 걸음, 작으면 큰 걸음이 좋습니다(뉴턴법). 파라미터 n개의 헤시안은 \(n^2\) 크기라 직접 쓸 수 없지만, Adam은 그래디언트 제곱의 이동 평균으로 대각 곡률을 대충 흉내 내고, Shampoo·K-FAC 계열은 블록 단위 근사를 씁니다. 안정적인 최대 학습률은 대략 \(2/\lambda_{\max}\) (\(\lambda_{\max}\): 헤시안의 최대 고윳값)이라는 분석이 있습니다.

    **미분 불가능한 점.** ReLU는 0에서 미분이 정의되지 않지만, 프레임워크는 관례로 0을 씁니다(서브그래디언트). 실수로 정확히 0에 떨어질 확률은 거의 없어 실무 문제는 없습니다.
