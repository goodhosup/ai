# 수학 기초

이 섹션은 이후 모든 페이지에 나오는 수학을 "AI에 필요한 만큼만" 정리합니다. 대학 수학 과목 전체가 필요한 것은 아닙니다. 벡터와 행렬 곱, 기울기(미분), 확률 분포, 엔트로피, 그리고 경사하강법이면 딥러닝 논문의 수식 대부분을 읽을 수 있습니다.

| 페이지 | 핵심 질문 |
|---|---|
| [벡터·행렬·텐서](linear-algebra.md) | 신경망의 계산은 왜 거의 전부 행렬 곱이고, 내적은 무엇을 재나? |
| [미분과 경사하강법](calculus.md) | 기울기는 무엇이고, 왜 기울기 반대 방향으로 가면 손실이 줄어드나? |
| [확률과 통계](probability.md) | 모델의 출력은 왜 확률 분포이고, 최대우도는 무엇을 하는 일인가? |
| [정보이론 (엔트로피·교차 엔트로피)](information.md) | LLM의 손실 함수인 교차 엔트로피와 perplexity는 무엇을 재나? |
| [최적화의 기초](optimization.md) | 볼록·비볼록, 안장점, 학습률은 학습에 어떤 영향을 주나? |

!!! basic "수학이 무서운 사람에게"
    딥러닝 수학의 대부분은 세 문장으로 요약됩니다.

    1. **데이터와 파라미터는 숫자의 배열(텐서)이고, 계산은 대부분 곱하고 더하기(행렬 곱)입니다.**
    2. **모델이 얼마나 틀렸는지를 숫자 하나(손실)로 잽니다.** 그 숫자는 보통 "정답에 붙인 확률의 로그"입니다.
    3. **손실이 줄어드는 방향(기울기의 반대)으로 파라미터를 조금씩 옮깁니다.** 이것을 수백만 번 반복하는 것이 학습입니다.

    이 섹션의 각 페이지는 이 세 문장 중 하나를 자세히 풀어 쓴 것입니다.
