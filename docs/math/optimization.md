# 최적화의 기초

!!! spec "핵심 논문 · 연도"
    Boyd·Vandenberghe, *Convex Optimization* (2004) · Dauphin 외, "Identifying and attacking the saddle point problem" (2014) · Keskar 외, "On Large-Batch Training: Sharp Minima" (2017) · Li 외, "Visualizing the Loss Landscape of Neural Nets" (2018) · Bottou·Curtis·Nocedal, "Optimization Methods for Large-Scale Machine Learning" (2018)

!!! basic "한눈에 보기"
    **최적화**는 "손실이 가장 작아지는 파라미터를 찾는 일"입니다.

    - 손실 지형이 **그릇 모양**(볼록)이면 어디서 출발해도 바닥 하나로 내려갑니다. 선형 회귀·로지스틱 회귀가 그렇습니다.
    - 신경망의 손실 지형은 **산맥**처럼 울퉁불퉁합니다(비볼록). 골짜기도 여럿, 말안장 모양 고개도 수없이 많습니다.
    - 그런데 놀랍게도 큰 신경망에서는 경사하강법으로 찾은 "적당한 골짜기"들이 대부분 비슷하게 좋습니다. 그래서 완벽한 최솟값보다 **빠르고 안정적으로 좋은 곳에 도착하는 것**이 실무의 목표입니다.

## 볼록과 비볼록 { .l2 }

| 항목 | 볼록 문제 | 비볼록 문제 (신경망) |
|---|---|---|
| 지형 | 그릇 하나 | 골짜기·고개·평지가 많음 |
| 국소 최솟값 | 곧 전역 최솟값 | 여러 개, 품질이 다를 수 있음 |
| 보장 | 수렴 증명 가능 | 일반적인 보장 없음 |
| 예 | 선형·로지스틱 회귀, SVM | MLP, CNN, 트랜스포머 |

## 손실 지형의 지형지물 { .l2 }

| 지형 | 설명 | 학습에 주는 영향 |
|---|---|---|
| 국소 최솟값 | 사방이 오르막인 골짜기 | 큰 모델에서는 생각보다 문제가 아님 |
| 안장점 | 어떤 방향은 오르막, 어떤 방향은 내리막 | 고차원에서 매우 흔함. 기울기가 0에 가까워 학습이 느려짐 |
| 평지(plateau) | 넓고 평평한 구간 | 손실이 한동안 정체되다가 갑자기 떨어지기도 함 |
| 좁은 골짜기 | 한 방향만 가파름 | 지그재그로 진동. 모멘텀·Adam이 도움 |
| 날카로운 vs 평평한 최솟값 | 바닥 주변이 가파른지 완만한지 | 평평한 곳이 일반화가 좋다는 가설 |

고차원에서는 모든 방향이 동시에 오르막인 점(국소 최솟값)보다 일부 방향만 오르막인 안장점이 훨씬 많습니다. 확률적 경사하강법의 잡음은 안장점에서 빠져나오는 데 도움이 됩니다.

## 제약과 정규화 { .l2 }

실제 목적 함수는 보통 "데이터 손실 + 벌점"입니다.

\[
\min_\theta \; \mathcal{L}_{\text{data}}(\theta) + \lambda\,\Omega(\theta)
\]

\(\Omega\)는 가중치 크기에 대한 벌점(L2, L1) 등이고, \(\lambda\)는 그 강도입니다. 벌점을 주면 지형이 더 그릇 모양에 가까워지고 과적합이 줄어듭니다 → [과적합과 정규화](../ml/overfitting.md).

## 배치 크기와 학습률 { .l2 }

| 설정 | 효과 |
|---|---|
| 큰 배치 | 그래디언트 잡음 감소, GPU 효율 상승, 같은 데이터에 대한 걸음 수 감소 |
| 작은 배치 | 잡음이 많아 탐색적, 걸음 수 많음 |
| 선형 스케일링 규칙 | 배치를 k배 키우면 학습률도 약 k배 (어느 한계까지) |
| 임계 배치 크기 | 이보다 키우면 걸음 수가 더 줄지 않아 계산만 낭비 |

## 코드로 보기 { .l2 }

좁고 긴 골짜기 \(f(x, y) = x^2 + 25y^2\)에서 기본 경사하강법과 모멘텀을 비교합니다.

```python
import numpy as np

def grad(p):                       # f = x^2 + 25 y^2
    return np.array([2 * p[0], 50 * p[1]])

def run(lr, beta=0.0, steps=100):
    p, v = np.array([-10.0, 1.0]), np.zeros(2)
    for _ in range(steps):
        v = beta * v + grad(p)      # beta=0이면 기본 경사하강법
        p = p - lr * v
    return np.linalg.norm(p)

print("GD      :", f"{run(0.035):.2e}")
print("Momentum:", f"{run(0.035, beta=0.8):.2e}")
print("GD lr=0.041 (발산):", f"{run(0.041):.2e}")
```

y 방향 곡률(50)이 x 방향(2)보다 25배 크기 때문에, 학습률은 y 방향이 발산하지 않는 한계(2/50 = 0.04)보다 작아야 하고 그 때문에 x 방향은 느리게 줄어듭니다. 모멘텀은 일관된 방향(x)으로는 속도를 쌓고 진동하는 방향(y)은 상쇄해 훨씬 빨리 도착합니다.

??? expert "전문가 노트 — 조건수, 과매개변수화, 안정성의 경계"
    **조건수.** 헤시안 최대·최소 고윳값의 비 \(\kappa = \lambda_{\max}/\lambda_{\min}\)이 클수록(위 예에서 25) 경사하강법은 느려집니다. 기본 경사하강법의 수렴 속도는 대략 \(1 - 1/\kappa\)의 거듭제곱, 모멘텀(헤비볼)은 최적 설정에서 \(1 - 1/\sqrt{\kappa}\)입니다. 정규화 층과 적응형 옵티마이저가 효과적인 이유 중 하나는 실질적인 조건수를 줄이기 때문입니다.

    **과매개변수화.** 파라미터가 데이터보다 훨씬 많으면 학습 손실을 0으로 만드는 해가 무수히 많고, 이들이 연결된 넓은 골짜기를 이룬다는 관찰이 있습니다(모드 연결성). 이 체제에서는 비볼록인데도 경사하강법이 전역 최솟값(학습 손실 0)에 잘 도달합니다. 어떤 해에 도달하는지는 옵티마이저의 **암묵적 정규화**가 정합니다. 예를 들어 선형 회귀에서 0에서 출발한 경사하강법은 최소 노름 해로 갑니다.

    **안정성의 경계(Edge of Stability).** Cohen 외(2021)는 전체 배치 경사하강법에서 헤시안 최대 고윳값이 학습 중 \(2/\eta\)까지 올라가 그 근처에 머물며, 손실이 단조 감소하지 않고 출렁이면서도 장기적으로 줄어든다는 것을 관찰했습니다. 고전적인 "학습률 < 2/λ" 분석만으로는 실제 학습을 설명하기 어렵다는 뜻입니다.

    **평평한 최솟값과 SAM.** Sharpness-Aware Minimization(2021)은 주변에서 가장 손실이 큰 점의 기울기로 업데이트해 평평한 곳을 선호하게 만듭니다. 계산이 약 2배 들어 대형 LLM 사전 학습에는 잘 쓰지 않습니다.
