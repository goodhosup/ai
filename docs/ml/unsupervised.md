# 군집과 차원 축소

!!! spec "핵심 논문 · 연도"
    Lloyd (1957/1982, k-평균) · Pearson (1901)·Hotelling (1933), PCA · Ester 외, "DBSCAN" (1996) · van der Maaten·Hinton, "t-SNE" (2008) · McInnes 외, "UMAP" (2018) · Arthur·Vassilvitskii, "k-means++" (2007)

!!! basic "한눈에 보기"
    정답(라벨) 없이 데이터에서 구조를 찾는 것이 **비지도 학습**입니다. 두 가지가 대표적입니다.

    1. **군집(clustering)** — 비슷한 것끼리 묶습니다. 구매 패턴이 비슷한 고객끼리, 증상이 비슷한 환자끼리. 몇 개의 무리로 나눌지, "비슷하다"를 무엇으로 잴지가 핵심입니다.
    2. **차원 축소** — 수백 개 특징을 핵심 몇 개로 줄입니다. 그림자를 보고 물체 모양을 짐작하듯, 가장 많은 정보를 담은 방향으로 데이터를 비춥니다. 768차원 임베딩을 2차원 지도로 그려 눈으로 보는 데도 씁니다.

## k-평균 군집 { .l2 }

1. 중심 k개를 고릅니다 (k-means++: 서로 멀리 떨어지게).
2. 각 점을 가장 가까운 중심에 배정합니다.
3. 각 군집의 평균으로 중심을 옮깁니다.
4. 배정이 바뀌지 않을 때까지 2–3을 반복합니다.

목표는 군집 내 제곱 거리 합(관성) \(\sum_k\sum_{\mathbf{x}\in C_k}\|\mathbf{x}-\boldsymbol{\mu}_k\|^2\)의 최소화입니다. 빠르고 단순하지만, 군집이 둥글고 크기가 비슷하다고 가정합니다.

| 알고리즘 | 군집 모양 | k 지정 | 잡음 처리 |
|---|---|---|---|
| k-평균 | 둥근 모양 | 필요 | 약함 |
| 가우시안 혼합 (GMM) | 타원, 확률적 소속 | 필요 | 보통 |
| DBSCAN | 임의 모양 (밀도 기반) | 불필요 (반경·최소 점 수) | 잡음 점을 따로 표시 |
| 계층적 군집 | 덴드로그램으로 여러 수준 | 나중에 자를 높이 선택 | 보통 |

k는 관성이 꺾이는 지점(엘보우)이나 실루엣 점수로 고르지만, 결국 업무 목적에 맞는지가 가장 중요합니다.

## 주성분 분석 (PCA) { .l2 }

데이터의 분산이 가장 큰 방향(제1 주성분), 그에 직교하면서 다음으로 큰 방향(제2 주성분)…을 찾아 그 축으로 투영합니다. 수학적으로는 공분산 행렬의 고유벡터, 또는 중심화한 데이터 행렬의 SVD입니다.

\[
X_c = U\Sigma V^\top \quad\Rightarrow\quad Z = X_cV_k
\]

| 용도 | 설명 |
|---|---|
| 압축 | 분산 95%를 유지하면서 차원을 크게 줄임 |
| 잡음 제거 | 작은 주성분을 버림 |
| 시각화 | 2–3차원으로 투영 |
| 전처리 | 상관된 특징을 독립적인 축으로 |

## t-SNE와 UMAP: 시각화용 비선형 축소 { .l2 }

PCA는 선형이라 휘어진 구조를 펴지 못합니다. t-SNE와 UMAP은 "원래 공간에서 가까운 점은 2차원에서도 가깝게"를 목표로 하는 비선형 방법입니다. 임베딩 공간을 들여다볼 때 많이 씁니다. 다만 **군집 사이 거리와 군집 크기는 의미가 없으니** 그림을 과하게 해석하지 않습니다.

## 코드로 보기 { .l2 }

8×8 손글씨 숫자(64차원)를 PCA로 줄이고, 라벨 없이 k-평균으로 묶어 봅니다.

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import adjusted_rand_score

X, y = load_digits(return_X_y=True)          # 1797장, 64차원
pca = PCA().fit(X)
cum = np.cumsum(pca.explained_variance_ratio_)
print("분산 90%에 필요한 주성분 수:", int(np.searchsorted(cum, 0.90)) + 1)

Z = PCA(n_components=30, random_state=0).fit_transform(X)
km = KMeans(n_clusters=10, n_init=10, random_state=0).fit(Z)
print(f"군집-숫자 일치도(ARI): {adjusted_rand_score(y, km.labels_):.3f}")
```

64차원 중 약 21개 주성분이면 분산 90%를 담고, 라벨을 전혀 쓰지 않은 군집이 실제 숫자와 상당히 일치합니다(ARI 약 0.67).

??? expert "전문가 노트 — 차원의 저주, 오토인코더와 PCA, 임베딩 공간의 군집"
    **차원의 저주.** 차원이 높아지면 무작위 점들 사이의 거리가 거의 같아져(최대·최소 거리 비가 1에 수렴) "가장 가까운 이웃"의 의미가 약해집니다. 거리 기반 군집이 고차원 원본 특징에서 잘 안 되는 이유이며, 차원 축소나 학습된 임베딩 공간에서 군집하는 것이 보통입니다.

    **오토인코더와 PCA.** 선형 활성화와 MSE 손실을 쓰는 오토인코더의 은닉층은 PCA와 같은 부분 공간을 학습합니다. 비선형 오토인코더는 휘어진 저차원 구조(다양체)를 학습할 수 있습니다 → [오토인코더와 VAE](../arch/vae.md).

    **임베딩 군집의 실무.** 문장 임베딩을 군집해 문의 유형을 자동 분류하거나 중복 문서를 찾는 일이 흔합니다. 이때 코사인 거리를 쓰고(벡터를 정규화한 뒤 k-평균), 군집마다 대표 문장을 LLM에게 요약시켜 이름을 붙이는 방식이 실용적입니다 → [임베딩과 표현 학습](../arch/embeddings.md).

    **이상 탐지.** 정상 데이터만 많고 이상 사례가 드문 제조·보안 분야에서는 밀도 추정(GMM), 재구성 오차(오토인코더), Isolation Forest 같은 비지도 방법으로 "평소와 다른 것"을 찾습니다.
