# 최신 동향

AI는 몇 달 단위로 판도가 바뀌는 분야입니다. 이 섹션은 앞의 장들에서 배운 원리가 **지금 실제로 어떻게 나타나고 있는지**를 정리하고, 앞으로의 질문을 던집니다. 다른 섹션과 달리 이 섹션의 사실 관계는 빠르게 낡으므로, 모든 내용은 **2026년 11월 기준**입니다.

| 페이지 | 핵심 질문 |
|---|---|
| [2025–2026 모델 지형](landscape-2026.md) | 최근 2년간 무엇이 바뀌었고, 주요 개발사와 모델은 어디에 서 있나? |
| [오픈 웨이트 모델](open-weights.md) | 누구나 내려받는 모델은 얼마나 강해졌고, 무엇을 주의해야 하나? |
| [AGI 논쟁과 앞으로의 과제](agi.md) | 범용 인공지능은 가까운가? 무엇이 남았고 무엇을 지켜봐야 하나? |

!!! basic "낡지 않는 읽기 방법"
    개별 모델 이름과 점수는 금방 바뀝니다. 대신 다음 질문으로 새 소식을 읽어 보세요.

    1. **무엇이 늘었나?** 학습 계산, 추론 시 계산, 데이터, 아니면 새로운 방법인가? → [사전 학습과 스케일링 법칙](../llm/pretraining.md), [추론 모델과 사고 사슬](../llm/reasoning.md)
    2. **어떻게 쟀나?** 벤치마크가 포화되지 않았는지, 조건이 같은지, 오차 범위는? → [평가와 벤치마크](../apps/evaluation.md)
    3. **얼마에 돌아가나?** 가격, 지연, 필요한 하드웨어는? → [시스템과 하드웨어](../systems/index.md)
    4. **무엇이 위험한가?** 새 능력이 새 오용이나 사고 가능성을 여는가? → [안전과 사회](../society/index.md)
