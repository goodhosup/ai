# 2025–2026 모델 지형

!!! spec "핵심 사건 · 연도"
    DeepSeek-R1 공개 (2025.1) · Llama 4, Qwen3 (2025.4) · Claude 4 (2025.5) · Kimi K2, GLM-4.5, Grok 4 (2025.7) · GPT-5, gpt-oss (2025.8) · Gemini 3 (2025.11) · DeepSeek-V4 (2026.4) · Claude Fable 5 (2026.6) · GPT-6 (2026.9) · Claude Opus 5.5·Sonnet 5.5 (2026.9) · 한국 독자 AI 파운데이션 모델 2차 평가 (2026.8)

!!! basic "한눈에 보기"
    이 페이지는 책에서 가장 빨리 낡는 페이지입니다. **2026년 11월 기준**으로 지난 2년 가까운 흐름을 정리합니다. 개별 모델 이름보다 **흐름**에 주목해 읽으면, 이 페이지가 낡은 뒤에도 쓸모가 있습니다.

    2025–2026년을 한 문장으로 요약하면 "**생각하는 모델과 일하는 모델의 시대**"입니다.

    - **추론 모델**: 답하기 전에 길게 생각하는 모델이 표준이 되었습니다. 수학·코딩·과학 문제에서 성능이 크게 뛰었습니다.
    - **에이전트**: 모델이 코드를 고치고, 웹을 조사하고, 컴퓨터를 조작하며 몇 시간짜리 일을 스스로 해내기 시작했습니다.
    - **오픈 웨이트의 추격**: 중국 연구소들을 중심으로 공개 모델이 최전선과의 격차를 몇 달 수준으로 좁혔습니다.
    - **가격 하락과 인프라 경쟁**: 같은 성능의 가격은 해마다 크게 떨어지는 한편, GW급 데이터센터 건설 경쟁이 벌어졌습니다.

## 코드로 보기 { .l2 }

최전선 모델의 **학습 연산량**이 얼마나 빠르게 늘었는지, 공개된 값과 외부 추정치로 추세를 맞춰 봅니다.

```python
import numpy as np
# 추정 학습 연산량 (FLOP). 공개 논문·Epoch AI 등 외부 추정 기반의 대략값
models = {"GPT-3 (2020.5)": (2020.4, 3.1e23), "Chinchilla (2022.3)": (2022.2, 5.8e23),
          "GPT-4 (2023.3, 추정)": (2023.2, 2e25), "Llama 3.1 405B (2024.7)": (2024.6, 3.8e25),
          "Grok 3 (2025.2, 추정)": (2025.1, 4.6e26)}
t = np.array([v[0] for v in models.values()]); c = np.log10([v[1] for v in models.values()])
slope, icept = np.polyfit(t, c, 1)                 # log10(FLOP) = slope × 연도 + 절편
print(f"연간 증가 배수: {10 ** slope:.1f}배  (2배가 되는 데 {12 * np.log10(2) / slope:.1f}개월)")
for label, year in [("2026년 11월", 2026.85), ("2028년 초", 2028.0)]:
    print(f"{label} 추세선 연장: {10 ** (slope * year + icept):.1e} FLOP")
```

다섯 점만으로 맞춘 추세는 **해마다 약 4.5배**, 5.5개월마다 두 배입니다. Epoch AI가 수백 개 모델로 분석한 "최전선 학습 연산량 연 4–5배 증가"와 일치합니다. 이 추세를 연장하면 2026년 말 최전선 학습은 10²⁷ FLOP을 넘는 규모로, [AI 규제](../society/regulation.md)의 10²⁶ FLOP 기준보다 한 자릿수 큽니다. 다만 추세선 연장은 예측이 아닙니다. 전력, 칩 공급, 데이터, 자본이 이 속도를 제한할 수 있고, 2025년 이후에는 사전학습보다 **강화학습과 추론 시 계산**에 쓰는 몫이 크게 늘어 "학습 연산량" 하나로 능력을 설명하기 어려워졌습니다.

??? expert "전문가 노트 — 계산 축의 이동, 벤치마크의 포화, 경제적 영향"
    **계산이 쓰이는 곳의 이동.** 2023년까지 능력 향상의 주된 축은 사전학습 규모였습니다. 2024–2026년에는 ① 검증 가능한 보상(수학 정답, 코드 테스트)을 이용한 대규모 강화학습, ② 추론 시 더 오래 생각하기(test-time compute), ③ 에이전트 환경에서의 학습이 핵심 축으로 더해졌습니다. 그래서 같은 기반 모델도 후속 학습만으로 몇 달 만에 크게 강해지고, 버전 번호가 소수점 단위로 빠르게 올라가는 현상이 나타났습니다 → [추론 모델과 사고 사슬](../llm/reasoning.md).

    **벤치마크의 수명.** MMLU, GSM8K, HumanEval은 2024년에, GPQA·AIME·SWE-bench Verified는 2025–2026년에 포화 단계에 들어갔습니다. 새 벤치마크(Humanity's Last Exam, FrontierMath, 긴 에이전트 과제)도 1–2년 안에 빠르게 점수가 오르는 패턴이 반복됩니다. 공개 점수표는 개발사 자체 보고가 많고 설정(생각 예산, 도구 사용, 시도 횟수)이 제각각이어서, 직접 비교할 때는 같은 조건의 독립 평가를 찾아야 합니다 → [평가와 벤치마크](../apps/evaluation.md).

    **경제적 영향.** 같은 품질 응답의 가격은 2023–2025년 사이 해마다 수십 배씩 떨어졌다는 분석이 있고, 반대로 추론 모델과 에이전트가 요청당 쓰는 토큰은 크게 늘었습니다. 소프트웨어 개발, 고객 지원, 문서 작업에서 생산성 효과가 보고되는 한편, 실제 업무 성과에 대한 측정 결과는 과제와 숙련도에 따라 엇갈려 연구가 계속되고 있습니다. AI 기업의 매출과 인프라 투자 규모가 모두 급증하면서 투자 과열 여부에 대한 논쟁도 이어지고 있습니다.
