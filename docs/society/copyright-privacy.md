# 저작권과 개인정보

!!! spec "핵심 논문 · 연도"
    Dwork 외, "Calibrating Noise to Sensitivity in Private Data Analysis" (2006) · Shokri 외, "Membership Inference Attacks" (2017) · Abadi 외, "Deep Learning with Differential Privacy (DP-SGD)" (2016) · Carlini 외, "Extracting Training Data from Large Language Models" (2021) · Carlini 외, "Extracting Training Data from Diffusion Models" (2023) · Nasr 외, "Scalable Extraction of Training Data from (Production) Language Models" (2023) · Longpre 외, "Consent in Crisis: The Rapid Decline of the AI Data Commons" (2024)

!!! basic "한눈에 보기"
    LLM과 이미지 생성 모델은 인터넷의 막대한 글과 그림으로 학습합니다. 여기서 두 가지 질문이 생깁니다.

    **저작권**: 남이 쓴 책, 기사, 그림을 허락 없이 학습에 써도 될까? AI가 만든 결과물이 원작과 비슷하면 누구 책임일까? AI가 만든 그림의 저작권은 누구에게 있을까?

    **개인정보**: 학습 데이터에 섞인 이름, 전화번호, 주소를 모델이 기억했다가 말해 버리면? 사용자가 챗봇에 입력한 회사 기밀이나 건강 정보는 어디에 쓰일까?

    도서관에 비유하면, 책을 많이 읽고 배우는 것(학습) 자체는 보통 문제가 되지 않지만, 책을 통째로 베껴 파는 것(복제)은 문제가 됩니다. AI는 그 경계가 모호하다는 것이 논쟁의 핵심입니다. 2026년 11월 기준으로 여러 나라에서 소송과 입법이 진행 중이며, 결론이 아직 정해지지 않은 부분이 많습니다. 이 페이지는 법률 자문이 아니라 쟁점의 정리입니다.

## 저작권의 쟁점 { .l2 }

| 쟁점 | 내용 | 현황 (2026년 11월 기준, 요약) |
|---|---|---|
| 학습 = 복제인가 | 학습 과정에서 저작물을 복사·저장 | 미국은 공정 이용(fair use) 판단, EU·일본·싱가포르는 텍스트·데이터 마이닝(TDM) 예외 조항 |
| 공정 이용 판단 | 변형적 이용인가, 원작 시장을 대체하는가 | 미국 1심 판결이 갈림: 합법 구매한 책 학습은 공정 이용 인정(Bartz v. Anthropic, Kadrey v. Meta, 2025), 경쟁 서비스 목적의 판례 데이터 이용은 불인정(Thomson Reuters v. Ross, 2025) |
| 불법 복제본 사용 | 해적판 사이트에서 받은 책으로 학습 | Bartz v. Anthropic에서 쟁점이 되어 15억 달러 규모 합의(2025) |
| 출력의 유사성 | 모델이 원문·원화를 그대로 재현 | 뉴욕타임스 v. OpenAI 등 진행 중. 개발사는 재현 방지 필터 적용 |
| 옵트아웃 | 저작권자가 학습 거부 의사 표시 | EU는 기계 판독 가능한 거부를 존중해야 함. robots.txt, AI 크롤러 차단 확산 |
| AI 산출물의 저작권 | 사람의 창작적 기여가 없는 AI 생성물 | 미국·한국 등 다수 국가에서 순수 AI 생성물은 저작물로 보지 않음. 사람이 선택·배열·수정한 부분은 보호 가능 |

한국 저작권법에는 2026년 11월 기준 명시적인 TDM 예외 조항이 없어, 공정 이용 일반 조항(제35조의5)의 해석과 입법 논의가 이어지고 있습니다. 실무에서는 **라이선스 계약**(언론사·출판사·이미지 업체와의 데이터 계약)이 빠르게 늘고 있습니다.

## 개인정보의 쟁점 { .l2 }

| 위험 | 설명 | 대응 |
|---|---|---|
| 학습 데이터 기억 | 드물게 반복된 문자열(전화번호, 주소, 코드 속 비밀키)을 모델이 그대로 기억 | 중복 제거, 개인정보 필터링, 차분 프라이버시 |
| 학습 데이터 추출 | 특정 프롬프트로 기억된 데이터를 끌어냄 | 출력 필터, 정렬 학습 |
| 멤버십 추론 | 특정 데이터가 학습에 쓰였는지 알아냄 | 과적합 방지, 차분 프라이버시 |
| 사용자 입력 | 프롬프트에 넣은 기밀·개인정보가 로그·학습에 사용 | 기업용 계약(학습 미사용), 보관 기간 제한, 사내 정책 (→ [RAG](../apps/rag.md)) |
| 추론 공격 | 공개 글 몇 개로 거주지·나이 등 사적 속성을 추측 | 정책·출력 제한 |
| 삭제 요구 | "내 정보를 지워 달라"를 학습된 모델에서 어떻게? | 머신 언러닝 연구, 데이터 단계에서 제거 후 재학습 |

한국 개인정보보호위원회는 공개된 개인정보를 AI 학습에 활용할 때의 기준과 생성형 AI 개발·활용을 위한 안내서를 내 왔고, EU GDPR은 정당한 이익, 목적 제한, 정보주체 권리를 AI 학습에도 적용합니다.

## 코드로 보기 { .l2 }

개인정보를 보호하면서 통계를 공개하는 대표 기술인 **차분 프라이버시**(differential privacy)의 라플라스 메커니즘입니다. "60세 이상은 몇 명인가?"라는 질문에 정확한 답 대신 잡음을 더한 답을 줍니다. 한 사람이 데이터에 있든 없든 답의 분포가 거의 같아서, 답을 보고 특정 개인의 존재를 알아낼 수 없게 됩니다.

```python
import numpy as np
rng = np.random.default_rng(0)
ages = rng.integers(20, 70, 1000)
true_count = int((ages >= 60).sum())                     # "60세 이상은 몇 명?"

def laplace_count(data, eps):
    return (data >= 60).sum() + rng.laplace(0, 1 / eps)  # 민감도 1 / ε 크기의 잡음

print("실제 값:", true_count)
for eps in (0.1, 1.0, 10.0):
    answers = [laplace_count(ages, eps) for _ in range(1000)]
    print(f"ε={eps:<4}  평균 {np.mean(answers):7.1f}  평균 오차 ±{np.mean(np.abs(np.array(answers) - true_count)):.1f}")
```

실제 값은 211명입니다. 프라이버시 예산 ε가 작을수록(보호가 강할수록) 잡음이 커서 ε = 0.1이면 평균 ±10명, ε = 1이면 ±1명, ε = 10이면 ±0.1명 틀립니다. 한 사람이 빠지거나 들어와도 개수는 1만 바뀌므로(민감도 1), 잡음 크기 1/ε면 두 경우의 출력 확률 비가 최대 e^ε로 묶입니다. 1,000명 집계에서 ±1명 오차는 통계로서 충분히 쓸 만하면서도 개인 정보는 보호됩니다. 이것이 **프라이버시와 유용성의 맞바꿈**이며, 미국 인구 조사(2020)와 여러 기업의 사용 통계에 쓰입니다.

??? expert "전문가 노트 — 기억의 메커니즘, DP-SGD, 출처 표시와 워터마크"
    **기억은 언제 일어나나.** 대형 모델일수록, 같은 문자열이 학습 데이터에 여러 번 나올수록, 학습을 오래 할수록 기억이 늘어납니다. Carlini 외(2021)는 GPT-2에서 이름·전화번호·이메일을 포함한 수백 개의 학습 문자열을 그대로 추출했고, Nasr 외(2023)는 운영 중인 챗봇에서도 같은 단어를 끝없이 반복시키는 공격으로 학습 데이터를 끌어냈습니다. 데이터 **중복 제거**는 기억을 크게 줄이면서 모델 품질도 높이는 가장 비용 효율적인 대책입니다.

    **DP-SGD.** 학습에 차분 프라이버시를 적용하려면 샘플마다 기울기를 계산해 크기를 잘라(clipping) 한 사람의 영향을 제한하고, 평균에 가우시안 잡음을 더합니다(Abadi 외 2016). 전체 학습의 프라이버시 손실은 회계 기법(모멘트 회계, RDP)으로 추적합니다. 이론적 보장은 강력하지만 같은 품질을 내려면 계산량이 크게 늘고 성능이 떨어져, 대형 LLM 사전학습보다는 민감 데이터로 하는 미세 조정이나 기기 내 학습(연합 학습)에 주로 쓰입니다.

    **출처 표시와 워터마크.** AI 생성물임을 표시하는 의무가 EU AI Act(투명성 의무), 중국(2025년 9월 표시 규정 시행), 한국 AI 기본법(생성형 AI 결과물 고지·표시)에 들어갔습니다. 기술적으로는 C2PA 같은 메타데이터 출처 증명과, 생성 시 토큰 선택 확률을 살짝 조정해 통계적 신호를 숨기는 **워터마크**(Kirchenbauer 외 2023, SynthID)가 쓰입니다. 텍스트 워터마크는 바꿔 쓰기에 약하고, 메타데이터는 쉽게 지워진다는 한계가 있어 여러 방법을 함께 씁니다.
