!!! basic "한눈에 보기"
    AI는 데이터에서 배웁니다. 데이터에 사회의 편견과 불균형이 담겨 있으면 AI도 그것을 그대로, 때로는 더 크게 배웁니다.

    - 과거 채용 기록으로 학습한 이력서 선별 AI가 특정 성별의 지원자를 낮게 평가한 사례가 보도되었습니다.
    - 얼굴 분석 시스템의 오류율이 밝은 피부의 남성보다 어두운 피부의 여성에서 수십 배 높았다는 연구(Gender Shades, 2018)가 있습니다.
    - LLM에게 "간호사"와 "엔지니어"에 대한 이야기를 쓰라고 하면 성별 고정관념이 드러나기도 합니다.

    **공정성**은 AI의 판단이 성별, 인종, 나이, 지역 같은 특성에 따라 부당하게 달라지지 않게 하는 문제입니다. 어려운 점은 "공정하다"의 정의가 **여러 가지**이고, 그 정의들이 **동시에 만족될 수 없는** 경우가 많다는 것입니다. 그래서 공정성은 기술 문제이면서 동시에 **어떤 가치를 우선할지 정하는 사회적 선택**입니다.

## 편향은 어디서 오나 { .l2 }

| 단계 | 편향의 원천 | 예 |
|---|---|---|
| 데이터 수집 | 대표성 부족 | 특정 집단 사진·언어 데이터가 적음 → 그 집단에서 성능 저하 |
| 레이블 | 과거의 차별이 정답에 반영 | 과거 승진 기록, 체포 기록을 정답으로 사용 |
| 특징 | 대리 변수 | 성별을 빼도 이름·우편번호·취미가 성별·인종을 대신함 |
| 목표 설정 | 측정하기 쉬운 것을 목표로 | 의료비 지출을 "건강 필요"의 대리로 써서 특정 집단 과소평가 (Obermeyer 외 2019) |
| 배포 | 쓰임새와 피드백 루프 | 예측 치안이 특정 지역에 경찰을 더 보내 기록이 더 쌓임 |
| LLM 특유 | 웹 텍스트의 고정관념, 언어별 데이터 불균형 | 영어 외 언어에서 품질·안전성 저하, 문화적 기본값의 편중 |

## 공정성의 정의들 { .l2 }

이진 분류(예: 대출 승인)에서 대표적인 기준입니다. Ŷ는 예측, Y는 실제, A는 집단입니다.

| 기준 | 조건 | 의미 |
|---|---|---|
| 인구 통계적 동등성 | P(Ŷ=1 ∣ A=a)가 집단마다 같음 | 승인율 자체가 같아야 함 |
| 기회 균등 | P(Ŷ=1 ∣ Y=1, A=a)가 같음 | **자격 있는 사람**의 승인율(TPR)이 같아야 함 |
| 균등화된 오즈 | TPR과 FPR이 모두 같음 | 맞히는 비율과 잘못 승인하는 비율 모두 같음 |
| 예측 동등성(보정) | P(Y=1 ∣ Ŷ=1, A=a)가 같음 | 승인된 사람의 실제 상환율이 집단마다 같음 |
| 개인 공정성 | 비슷한 사람은 비슷하게 대우 | "비슷함"의 정의가 관건 |

**양립 불가능성 정리**: 집단 간 기저율(실제 자격자 비율)이 다르면, 완벽한 예측기가 아닌 한 보정과 균등화된 오즈를 동시에 만족할 수 없습니다(Kleinberg 외 2016, Chouldechova 2017). 2016년 COMPAS 재범 예측 논쟁에서 ProPublica와 개발사가 서로 다른 기준을 근거로 각자 "편향됐다", "공정하다"고 주장한 것이 이 정리의 실제 사례입니다.

## 코드로 보기 { .l2 }

가상의 대출 심사 모델에서 집단별 승인율과 기회 균등(TPR)을 측정하고, 집단별 기준값을 조정해 봅니다. 두 집단은 실제 상환 능력의 기저율이 다르고(50% 대 30%), 모델 점수는 집단 B에 불리하게 편향되어 있습니다.

```python
import numpy as np
rng = np.random.default_rng(0)
n = 5000
group = rng.integers(0, 2, n)                            # 0: 집단 A, 1: 집단 B
y = rng.random(n) < np.where(group == 0, 0.5, 0.3)       # 실제 상환 능력 기저율이 다름
score = y * 1.0 + rng.normal(0, 0.6, n) - 0.3 * group    # 모델 점수: 집단 B에 불리한 편향

def report(th):
    for g, name in [(0, "A"), (1, "B")]:
        m = group == g
        pred = score[m] > th[g]
        tpr = pred[y[m]].mean()                          # 기회 균등: 자격 있는 사람의 승인율
        print(f"  {name}: 승인율 {pred.mean():.2f}  자격자 승인율(TPR) {tpr:.2f}")

print("같은 기준 0.5"); report({0: 0.5, 1: 0.5})
print("집단별 기준 (TPR 맞춤)"); report({0: 0.5, 1: 0.25})
```

같은 기준(0.5)을 쓰면 집단 B는 승인율 0.26, **상환 능력이 있는 사람의 승인율(TPR)도 0.67**로 A(0.80)보다 낮습니다. 기저율 차이만이 아니라 점수 편향 때문에 자격 있는 B 지원자가 더 많이 탈락한 것입니다. B의 기준을 0.25로 낮추면 TPR이 0.79로 A와 거의 같아집니다(기회 균등). 하지만 승인율은 여전히 다르므로(0.51 대 0.36) 인구 통계적 동등성은 만족하지 않고, 집단별로 다른 기준을 쓰는 것 자체가 법적으로 허용되지 않는 영역도 있습니다. 어떤 기준을 택할지는 코드가 아니라 **맥락과 사회적 합의**가 정합니다.

??? expert "전문가 노트 — LLM 편향 측정, 완화 기법, 문서화"
    **LLM 편향 측정.** 분류기와 달리 LLM은 출력이 열려 있어 측정이 어렵습니다. BBQ는 모호한 문맥("두 사람 중 누가 수학을 못하나?")에서 모델이 고정관념에 기대 답하는지를 보고, KoBBQ(2023)는 이를 한국 문화에 맞게 다시 만들었습니다(단순 번역이 아니라 한국 사회의 고정관념 범주를 반영). 그 밖에 이름만 바꾼 동일한 이력서·질문에 대한 응답 차이 측정(반사실 평가), 생성 텍스트의 고정관념 연관도 측정이 쓰입니다. 명시적 질문에는 공정하게 답하면서도 이름 같은 암묵적 단서에는 편향을 보이는 경우가 보고되어 두 방식을 함께 써야 합니다.

    **완화 기법.** ① 전처리: 데이터 재표집·재가중, 반사실 데이터 증강(성별 단어를 바꾼 문장 추가). ② 학습 중: 공정성 제약을 손실에 추가, 적대적 학습으로 표현에서 집단 정보 제거. ③ 후처리: 위 코드처럼 집단별 기준 조정(Hardt 외 2016). LLM에서는 선호 학습 데이터와 시스템 프롬프트로 조정하지만, 과도한 교정이 역사적 사실을 왜곡하는 등 다른 문제를 만든 사례도 있어 균형이 필요합니다.

    **문서화와 감사.** 모델 카드(용도, 집단별 성능, 한계), 데이터시트(데이터의 출처와 구성), 영향 평가가 표준 관행이 되었습니다. EU AI Act와 한국 AI 기본법은 채용·대출·교육 같은 고위험/고영향 영역에서 데이터 품질 관리, 위험 평가, 설명, 사람의 감독을 요구합니다 → [AI 규제](regulation.md).
