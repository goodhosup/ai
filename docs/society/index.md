# 안전과 사회

AI가 강력해지고 일상 깊숙이 들어오면서, "무엇을 할 수 있나"만큼 "**어떻게 안전하고 공정하게 쓸 것인가**"가 중요해졌습니다. 이 섹션은 기술을 만드는 사람과 쓰는 사람 모두가 알아야 할 위험과 책임을 다룹니다. 수식은 적지만, 각 페이지에 개념을 직접 확인해 보는 짧은 코드를 넣었습니다.

| 페이지 | 핵심 질문 |
|---|---|
| [정렬과 AI 안전](safety.md) | AI가 "시킨 대로"가 아니라 "원하는 대로" 하게 하려면? 어떤 위험이 있고 어떻게 대비하나? |
| [편향과 공정성](fairness.md) | AI의 편향은 어디서 오고, "공정하다"는 무엇으로 재나? |
| [저작권과 개인정보](copyright-privacy.md) | 남의 저작물로 학습해도 되나? 모델이 개인정보를 기억하면? |
| [AI 규제 (EU AI Act·AI 기본법)](regulation.md) | 각국은 AI를 어떻게 규율하고, 개발자와 기업은 무엇을 준비해야 하나? |

!!! basic "세 가지 관점"
    - **개인 사용자**: AI의 답을 검증하는 습관, 민감 정보 입력 주의, AI 생성물 표시 확인.
    - **개발자·기업**: 위험 평가와 문서화, 편향·안전 평가 세트, 사람의 감독 절차, 법적 의무 확인.
    - **사회**: 어떤 위험을 받아들이고 어떤 가치를 우선할지에 대한 합의. 기술만으로는 답할 수 없는 질문입니다.

!!! warning "시점과 법률"
    규제와 소송은 빠르게 바뀝니다. 이 섹션의 법·제도 내용은 **2026년 11월 기준**의 개요이며 법률 자문이 아닙니다. 실제 적용 전에는 최신 법령, 시행령, 감독 기관의 지침을 확인하세요.
