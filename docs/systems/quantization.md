# 양자화와 경량화

!!! spec "핵심 논문 · 연도"
    Han 외, "Deep Compression" (2015) · Hinton 외, "Distilling the Knowledge in a Neural Network" (2015) · Jacob 외, "Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference" (2017) · Dettmers 외, "LLM.int8()" (2022) · Frantar 외, "GPTQ" (2022) · Xiao 외, "SmoothQuant" (2022) · Dettmers 외, "QLoRA" (2023) · Lin 외, "AWQ" (2023) · Ma 외, "BitNet b1.58" (2024) · Ashkboos 외, "QuaRot" (2024)

!!! basic "한눈에 보기"
    70B 모델의 가중치를 16비트로 저장하면 140GB입니다. 이를 4비트로 바꾸면 35GB가 되어 고급 PC 한 대에서도 돌아갑니다. 이렇게 숫자를 **더 적은 비트로 표현**하는 것이 **양자화**입니다.

    사진에 비유하면 이해가 쉽습니다. 수백만 색을 쓰는 원본 사진을 256색으로 줄여도 대부분은 거의 똑같아 보입니다. 16색까지 줄이면 티가 나기 시작하지만, 색을 영리하게 고르면 여전히 쓸 만합니다.

    양자화가 중요한 이유는 [GPU와 행렬 연산](gpu.md)에서 본 것처럼 LLM 추론이 **메모리 한계**이기 때문입니다. 비트 수를 절반으로 줄이면 읽을 바이트가 절반이 되어, 대략 그만큼 빨라지고 더 작은 기기에 들어갑니다.

    양자화 말고도 모델을 가볍게 만드는 방법이 있습니다.

    - **증류**: 큰 모델(선생)의 답을 작은 모델(학생)이 따라 배우게 합니다.
    - **가지치기**: 중요하지 않은 가중치나 층을 잘라 냅니다.
    - **작은 모델 잘 만들기**: 좋은 데이터로 오래 학습한 작은 모델이 대충 줄인 큰 모델보다 나을 때가 많습니다.

## 양자화의 기본 { .l2 }

가장 단순한 **대칭 선형 양자화**는 실수 w를 스케일 s로 나눠 반올림합니다.

$$q = \text{round}(w / s), \quad s = \frac{\max|w|}{2^{b-1}-1}, \quad \hat w = q \cdot s$$

int8이면 −127~127, int4면 −7~7의 정수만 씁니다. 핵심 설계 선택은 **스케일 하나를 몇 개의 값이 공유하느냐**(텐서 전체 / 출력 채널마다 / 32–128개 그룹마다)입니다. 공유 범위가 좁을수록 정확하지만 스케일 저장 비용이 늡니다.

| 구분 | 선택지 | 설명 |
|---|---|---|
| 무엇을 | 가중치만 (W4A16, W8A16) | 메모리·대역폭 절약. 계산은 16비트로 복원해서. 로컬 추론의 주류 |
| | 가중치 + 활성값 (W8A8, FP8) | 정수/FP8 연산 장치를 직접 사용 → 프리필도 빨라짐. 데이터센터 서빙 |
| | KV 캐시 (FP8, int4) | 긴 문맥 메모리 절약 |
| 언제 | 학습 후 양자화 (PTQ) | 작은 보정 데이터로 몇 분~몇 시간. 가장 흔함 |
| | 양자화 인식 학습 (QAT) | 학습 중 양자화 오차를 시뮬레이션. 4비트 이하에서 품질 좋음 |
| 형식 | INT8/INT4 | 균일 간격 |
| | FP8, MXFP4·NVFP4 | 지수가 있어 작은 값을 촘촘히. 블록 스케일 |
| | NF4, 코드북 | 정규분포 가중치에 맞춘 비균일 간격 |

## 대표 방법 { .l2 }

| 방법 | 핵심 아이디어 | 비고 |
|---|---|---|
| LLM.int8() | 이상치가 있는 활성값 채널만 16비트로 분리 | 대형 모델 이상치 문제를 처음 보고 |
| GPTQ | 층별로 가중치를 하나씩 양자화하며 남은 가중치를 보정(2차 정보) | 3–4비트 PTQ의 표준 중 하나 |
| AWQ | 활성값이 큰 채널의 가중치를 미리 키워 보호 | 빠르고 견고 |
| SmoothQuant | 활성값의 이상치를 가중치 쪽으로 옮겨 둘 다 양자화하기 쉽게 | W8A8 |
| QuaRot / SpinQuant | 직교 회전으로 이상치를 고르게 펴서 4비트 활성값까지 | 회전은 출력에 영향 없음 |
| GGUF k-quants | 블록별 스케일 + 중요 층에 더 많은 비트 | llama.cpp 로컬 실행 형식 |
| BitNet b1.58 | 가중치를 {−1, 0, +1}로 처음부터 학습 | 곱셈이 덧셈으로. 연구 단계 |

## 코드로 보기 { .l2 }

512×512 가중치 행렬을 int8·int4로 양자화해 출력 오차를 비교합니다. 일부러 **이상치** 하나(다른 값보다 40배 큰 값)를 넣었습니다.

```python
import numpy as np
rng = np.random.default_rng(0)
W = rng.standard_normal((512, 512)).astype(np.float32) * 0.02
W[3, 7] = 0.8                                  # 이상치(outlier) 하나
x = rng.standard_normal(512).astype(np.float32)

def quantize(W, bits, group=None):
    qmax = 2 ** (bits - 1) - 1                 # int8: 127, int4: 7
    Wg = W.reshape(-1, group) if group else W  # group=None이면 행(출력 채널)마다 스케일 1개
    scale = np.abs(Wg).max(axis=1, keepdims=True) / qmax
    q = np.clip(np.round(Wg / scale), -qmax, qmax).astype(np.int8)
    return (q * scale).reshape(W.shape)        # 복원(dequantize)

ref = W @ x
for name, Wq in {"int8 채널별": quantize(W, 8), "int4 채널별": quantize(W, 4),
                 "int4 그룹 128": quantize(W, 4, group=128)}.items():
    err = np.linalg.norm(Wq @ x - ref) / np.linalg.norm(ref)
    print(f"{name:13s} 출력 상대오차 {err:.4f}")
print("이상치가 있는 행 3의 int4 오차:", round(float(np.abs(quantize(W, 4)[3] - W[3]).mean() / np.abs(W[3]).mean()), 3))
print("이상치가 없는 행 4의 int4 오차:", round(float(np.abs(quantize(W, 4)[4] - W[4]).mean() / np.abs(W[4]).mean()), 3))
```

int8은 출력 오차가 **0.7%**로 거의 손실이 없습니다. int4는 **14.8%**로 크게 늘고, 128개 그룹마다 스케일을 두면 12.3%로 줄어듭니다. 더 극적인 것은 행별 결과입니다. 이상치가 없는 행은 int4 오차가 12%인데, 이상치가 있는 행 3은 **91%**입니다. 0.8이라는 큰 값에 스케일을 맞추느라 나머지 작은 값들(±0.02 수준)이 거의 모두 0으로 반올림되었기 때문입니다. 실제 LLM에도 이런 이상치가 특정 채널에 체계적으로 나타나며, 위 표의 방법들은 대부분 **이상치를 어떻게 다루느냐**에 대한 답입니다. 실제 모델에서는 GPTQ·AWQ 같은 보정 덕분에 4비트에서도 벤치마크 점수 하락이 보통 1–2점 이내입니다.

??? expert "전문가 노트 — 품질 측정, 증류와 가지치기, 저비트 학습"
    **품질은 어떻게 재나.** 퍼플렉서티 증가가 가장 빠른 지표지만, 긴 추론·코딩·다국어처럼 어려운 과제에서 손실이 먼저 드러납니다. 한국어처럼 학습 데이터 비중이 작은 언어는 양자화에 더 민감할 수 있으므로 쓰려는 과제로 직접 평가해야 합니다. 일반적인 경험칙으로 8비트는 거의 무손실, 4비트는 잘 하면 소폭 손실, 3비트 이하는 모델과 방법에 따라 편차가 큽니다. 같은 메모리라면 "큰 모델 4비트"가 "작은 모델 16비트"보다 나은 경우가 많습니다.

    **증류.** 학생이 정답 레이블 대신 선생의 **확률 분포**(소프트 타깃)를 따라 배우면, "정답은 아니지만 그럴듯한 후보"에 대한 정보까지 전달됩니다. LLM에서는 선생 모델이 생성한 응답·추론 과정으로 학생을 SFT 하는 방식(시퀀스 수준 증류)이 흔하며, 2025년 DeepSeek-R1의 추론 과정을 작은 모델들에 증류한 사례가 대표적입니다. 작은 모델의 성능 상당 부분이 큰 모델로부터의 증류에서 옵니다.

    **가지치기와 희소성.** 개별 가중치를 0으로 만드는 비구조적 가지치기는 압축률은 높지만 일반 하드웨어에서 빨라지지 않습니다. NVIDIA GPU는 4개 중 2개가 0인 **2:4 구조적 희소성**을 하드웨어로 지원해 최대 2배 가속합니다. 층·헤드·채널 단위로 잘라 낸 뒤 증류로 회복하는 방식(예: Minitron)이 작은 모델 계열을 만드는 데 쓰입니다.

    **저비트 학습.** 추론뿐 아니라 학습도 저정밀도로 옮겨 가고 있습니다. DeepSeek-V3(2024)는 블록 단위 스케일을 쓴 **FP8 학습**을 671B 규모에서 성공시켰고, Blackwell 세대는 MXFP4·NVFP4 형식을 하드웨어로 지원해 4비트 학습 연구가 진행 중입니다. 2025년에는 MXFP4로 배포된 오픈 웨이트 모델(gpt-oss)도 나왔습니다. 정밀도를 낮출수록 학습 안정성(→ [초기화와 학습 안정성](../dl/training-stability.md))을 지키기 위한 스케일 관리가 중요해집니다.
